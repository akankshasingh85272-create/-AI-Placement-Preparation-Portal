# AI Placement Preparation Portal

## About the Project

AI Placement Preparation Portal is a web application that I built to help students prepare for their placement journey in one place.

While preparing for placements, students usually have to switch between different platforms for coding practice, interview preparation, and getting help with coding problems. I wanted to build a simple platform where these things could be brought together.

The project is still under development, and I am gradually adding more features and improving the existing ones.

## What I Have Built

- User registration and login
- Secure user authentication
- Coding practice section
- Topic-wise coding questions
- Coding solution submission
- AI coding assistant
- MongoDB database for storing user and question data
- REST APIs using Node.js and Express.js

**AI**

## How It Works

A user can create an account and log in to the portal. After logging in, they can practice coding questions, submit their solutions, and use the AI assistant when they need help understanding a coding problem.

The backend handles authentication, questions, submissions, and communication with the AI service, while MongoDB is used to store the application data.
